Importer un relevé Crédit Mutuel ou CIC au format CSV

Les deux banques partagent la même plateforme de banque en ligne et le même export. La marche à suivre est identique dans les deux espaces clients.

Le Crédit Mutuel et le CIC font partie du même groupe et utilisent la même plateforme technique. Leur export d'opérations est donc identique : mêmes formats proposés, mêmes colonnes, même chemin dans l'espace client. Le Crédit Mutuel propose plusieurs formats d'export ; deux d'entre eux se chargent directement dans Pécule : le CSV et le QIF. Le CSV est celui qui donne les meilleurs libellés.

1. Exporter le CSV

  1. Connectez-vous à votre espace client creditmutuel.fr ou cic.fr.
  2. Ouvrez le compte à exporter (rubrique Comptes et contrats).
  3. Cliquez sur « Exporter mes opérations » — le lien apparaît dans le menu latéral du compte ou sous la liste des opérations.
  4. Choisissez la période (le CIC permet des plages larges), puis le format Excel (CSV). L'option Quicken (QIF) se charge elle aussi dans Pécule ; en revanche l'option Microsoft Money (OFX) n'est pas prise en charge.
  5. Enregistrez le fichier sur votre PC. Il porte un nom du type CM_JJMMAAAA_JJMMAAAA.csv (ou CIC_...).
CSV et QIF : ces deux formats se chargent dans Pécule. Le CSV est celui qui préserve le mieux les libellés d'origine ; le QIF est plus léger si vous voulez juste les mouvements sans le détail. Le format OFX, lui, n'est pas reconnu par Pécule.

2. Importer le fichier dans Pécule

  1. Ouvrez Pécule.
  2. Glissez-déposez le fichier sur la fenêtre, ou cliquez sur 📥 Importer CSV dans le menu de gauche.
  3. Pécule reconnaît les colonnes par leur nom (Date operation, Libelle, Debit, Credit) et affiche un compte rendu détaillé : lignes importées, doublons ignorés, opérations pointées.
  4. Vos règles de catégorisation s'appliquent au fil de l'import. Les échéances que vous aviez inscrites d'avance sont complétées par la vraie ligne du relevé au lieu d'être dupliquées.

Vous pouvez réimporter un nouveau relevé chaque mois : les lignes déjà enregistrées sont reconnues et ignorées. Voir la page d'import CSV pour le détail des règles.

3. Le format CSV Crédit Mutuel / CIC en détail

En-tête typique

Date operation;Date de valeur;Montant;Libelle;Solde

C'est un format plus dépouillé que celui du Crédit Agricole ou de BPCE : une seule colonne Montant (déjà signée, négative pour les dépenses), un seul libellé sans version simplifiée, et la colonne Solde qui donne le solde du compte après chaque opération.

Selon la formule d'export choisie, on trouve parfois quelques colonnes supplémentaires (référence, sous-catégorie interne). Pécule les reconnaît toutes par mot-clé, sans tenir compte des accents ni des majuscules.

Encodage et séparateur

  • Séparateur : point-virgule ;
  • Encodage : Windows-1252 (Latin-1) — parfois UTF-8 sur les exports les plus récents. Pécule essaie l'un puis l'autre automatiquement.
  • Décimales : virgule française (-42,50).
  • Dates : format JJ/MM/AAAA.
Le CSV du Crédit Mutuel ne contient pas de colonne de pointage. Faute de cette information, Pécule importe les opérations comme non pointées : c'est à vous de les pointer d'un clic, une fois vérifiées. (Avec les banques dont le relevé comporte une colonne « Pointage », Pécule les pointe automatiquement.)
