Importer un relevé Banque Populaire ou Caisse d'Épargne (CSV)

Le groupe BPCE (Banque Populaire, Caisse d'Épargne, Palatine) utilise un format CSV commun. Voici comment l'exporter, puis le charger dans Pécule.

La Banque Populaire, la Caisse d'Épargne et la Banque Palatine font partie du même groupe (BPCE) et partagent la même plateforme technique. Leurs exports CSV sont quasiment identiques : mêmes colonnes, même séparateur point-virgule, même encodage Windows-1252. Pécule les lit tels quels, sans détour par Excel.

1. Exporter le CSV

Banque Populaire (Cyberplus)

  1. Connectez-vous à Cyberplus — l'espace client de votre Banque Populaire régionale.
  2. Ouvrez le compte à exporter dans la rubrique Comptes.
  3. Au-dessus ou en-dessous de la liste des opérations, cliquez sur « Télécharger » (icône flèche vers le bas).
  4. Choisissez la période, puis le format Excel (CSV).
  5. Enregistrez le fichier — son nom commence par le numéro du compte, par exemple 04210755852_20260826.csv.

Caisse d'Épargne (Direct Ecureuil)

  1. Connectez-vous à votre espace client Direct Ecureuil.
  2. Ouvrez le compte concerné.
  3. Cliquez sur « Télécharger les opérations » — le bouton se trouve au-dessus ou sous la liste des lignes.
  4. Format à choisir : CSV (Excel). Sélectionnez la période puis validez.
L'export couvre l'historique visible en ligne — quelques mois en général. Pour de vieux mois, filtrez la période avant de télécharger, ou récupérez les relevés PDF mensuels.

Carte à débit différé

Pour un compte associé à une carte à débit différé, un second fichier peut être proposé, dédié aux opérations carte (nom du type carte_XXXX_20260826.csv). Vous pouvez l'importer aussi : Pécule reconnaît les récapitulatifs « DEBIT DIFFERE » et les écarte pour éviter de compter deux fois les mêmes achats.

2. Importer le fichier dans Pécule

  1. Ouvrez Pécule.
  2. Glissez-déposez le CSV sur la fenêtre, ou cliquez sur 📥 Importer CSV dans le menu de gauche.
  3. Pécule reconnaît les colonnes par leur nom (Date operation, Libelle, Debit euros, Credit euros, Reference, Pointage) et affiche un compte rendu détaillé.
  4. Les opérations passées en banque arrivent déjà pointées (colonne Pointage operation remplie), et les échéances que vous aviez inscrites d'avance sont complétées par la vraie ligne du relevé, sans doublon.

Vous pouvez réimporter un nouveau relevé chaque mois : les lignes déjà enregistrées sont reconnues et ignorées. Voir la page d'import CSV pour le détail des règles.

3. Le format CSV BPCE en détail

En-tête typique

Date operation;Date de valeur;Libelle simplifie;Libelle operation;Reference;Informations complementaires;Type operation;Categorie;Sous categorie;Debit euros;Credit euros;Pointage operation

C'est le même en-tête pour la Banque Populaire, la Caisse d'Épargne et la Banque Palatine. Les colonnes Débit et Crédit sont séparées : Pécule les rassemble automatiquement en un montant signé. La colonne Pointage operation vaut x pour une opération passée en banque et un espace ou 0 pour une opération en cours.

Encodage et séparateur

  • Séparateur : point-virgule ;
  • Encodage : Windows-1252 (parfois UTF-8 sur les exports récents). Pécule essaie l'un puis l'autre automatiquement.
  • Décimales : virgule française (-42,50), avec espaces facultatifs pour les milliers.
  • Dates : format JJ/MM/AAAA.
Ouvert directement dans Excel, le fichier s'affiche mal : toutes les colonnes se retrouvent tassées dans une seule cellule, et les accents deviennent illisibles (Ã© au lieu de é). Cause : Excel attend souvent la virgule et l'UTF-8, or le CSV BPCE utilise le point-virgule et le Windows-1252. Pécule, lui, connaît ce format et le lit tel quel.
