PECULE - version 1.33.0

Application Windows GRATUITE et open source (licence MIT) de gestion de
comptes et de budget personnel. Aucune installation de Python requise.

-------------------------------------------------------------------
UTILISATION
-------------------------------------------------------------------
- Decompressez ce dossier ou vous voulez (le programme est portable).
- Double-cliquez sur << Pecule.exe >> pour lancer l'application.
- Au 1er lancement, si Windows affiche un avertissement (appli non signee) :
  cliquez << Informations complementaires >> puis << Executer quand meme >>.
- Vos donnees sont enregistrees dans un fichier unique, << comptes.db >>,
  cree automatiquement au 1er lancement. Une sauvegarde quotidienne est
  faite dans un sous-dossier << sauvegardes >>, a cote de lui.
  OU se trouve ce fichier ? Deux cas possibles :
  * S'il existe deja un << comptes.db >> A COTE de l'executable, c'est
    celui-la qui sert. L'installation reste portable : tout tient dans un
    seul dossier, que vous pouvez deplacer ou copier tel quel. C'est le cas
    quand vous mettez a jour une installation existante.
  * Sinon (installation neuve), il est range dans votre dossier personnel :
    C:\Users\<votre nom>\AppData\Local\Pecule
    Vos donnees y sont mieux protegees : une mise a jour du programme ne
    peut pas les effacer.
  Dans les deux cas, l'onglet << Notice >> de l'application affiche le
  chemin exact du dossier utilise.
  Si vous avez installe l'application avec Scoop, comptes.db et le dossier
  << sauvegardes >> sont ranges dans << scoop\persist\pecule >> :
  ils sont conserves d'une mise a jour a l'autre.

-------------------------------------------------------------------
MISE A JOUR depuis une version precedente
-------------------------------------------------------------------
La bonne facon : decompressez cette archive PAR-DESSUS votre dossier
Pecule existant, en acceptant de remplacer les fichiers. Elle ne
contient ni << comptes.db >> ni le dossier << sauvegardes >> : vos
operations ne peuvent donc pas etre ecrasees. Seuls Pecule.exe et le
dossier _internal sont remplaces.

A NE PAS FAIRE : supprimer l'ancien dossier avant de coller le
nouveau, ou renommer le nouveau dossier a la place de l'ancien. La
c'est bien votre comptes.db qui disparait. En cas de doute, copiez
comptes.db ailleurs avant de commencer : c'est un seul fichier.

<< J'ai mis a jour et l'application est VIDE >> : vous avez lance le
nouveau Pecule.exe depuis un autre dossier (Telechargements, par
exemple). Vos donnees ne sont pas perdues : elles sont restees dans le
comptes.db de votre ancien dossier. Pecule vous le dit au lancement et
propose de reprendre ce fichier - bouton << Reprendre mes donnees >>,
ou << Reprendre un fichier >> dans le menu de gauche. Il est copie,
l'original n'est pas touche.

Avec Scoop, rien a faire : << scoop update pecule >> conserve vos
donnees d'une version a l'autre.

-------------------------------------------------------------------
FONCTIONS
-------------------------------------------------------------------
- Import des releves bancaires au format CSV. Les colonnes sont
  reconnues par leur nom, quelle que soit la banque francaise.
  Les operations importees sont pointees : un releve ne porte que des
  operations deja passees en banque, votre solde est donc juste des le
  premier import. Seule exception, les releves qui portent eux-memes
  une colonne "Pointage" (BPCE) : leur indication fait foi.
  Si rien ne s'importe, le message explique pourquoi : separateur
  virgule, colonnes mal nommees ou dates hors du format JJ/MM/AAAA.
- Import au format OFX, propose par la plupart des banques a cote du
  CSV et parfois a sa place. Les deux versions du format sont lues.
  Le releve de la carte a debit differe est reconnu : ses achats ne
  pesent sur le solde qu'au jour du prelevement groupe.
- Import au format QIF, pour reprendre l'historique d'un autre logiciel
  (Microsoft Money, Quicken, GnuCash, HomeBank...). Dates et montants
  europeens ou americains sont reconnus automatiquement. Un fichier
  contenant plusieurs comptes est refuse : Pecule suit un seul compte
  par fichier de donnees, exportez un compte a la fois.
- Categorisation automatique des le premier import : les operations sont
  classees d'apres leur libelle (CARREFOUR -> Alimentation, EDF ->
  Logement...). Vos propres regles et la categorie fournie par la banque
  passent avant ; ce classement ne comble que ce qui resterait
  "Non classe".
- Budgets mensuels avec barres de progression, previsionnel des
  operations recurrentes, bilan avec graphiques, rapport mensuel
  (impression / PDF), rapprochement (pointage).
- Pointage EN MASSE : selectionnez plusieurs lignes (Maj+clic, Ctrl+clic,
  Ctrl+A), puis barre d'espace ou clic droit pour toutes les pointer ou
  depointer d'un coup. La touche Suppr porte aussi sur la selection.
- Vos propres categories : le champ Categorie s'ecrit librement. Tapez
  "Animaux" ou "Vacances" et la categorie est creee, avec sa couleur et
  son budget possible.
- Le Bilan previent quand le solde de depart n'est pas renseigne, et
  quand des operations sont anterieures a la date de depart (leur total
  n'entre pas dans le solde : il est cense etre deja compris dedans).
- Une seule fenetre a la fois sur les memes donnees : deux fenetres
  ouvertes en meme temps se contrediraient.
- Cartes a DEBIT DIFFERE : les achats n'entrent dans le solde qu'au jour
  du prelevement groupe. Un bandeau reprend les chiffres de votre espace
  bancaire (prochain prelevement, operations en cours, achats a debiter).
  La ligne recapitulative du releve (<< DEBIT DIFFERE... >>) n'est jamais
  importee : elle ferait doublon avec les achats deja detailles.
- Projection du compte a 15 jours : ce qui va sortir, ce qui va rentrer,
  et le solde prevu, d'apres vos operations recurrentes.
- Echeances du mois : le bouton << Generer les echeances du mois >> de
  l'onglet Previsionnel cree en une fois tout ce qui doit encore etre
  debite ou encaisse. Ces operations sont NON pointees (marquees par un
  sablier) : elles n'entrent pas dans le solde en banque tant qu'elles ne
  sont pas passees. A l'import du releve, chacune est completee avec la
  date et le montant reels au lieu de faire doublon, meme si la banque la
  passe un autre jour.
- Bandeau << Ce mois-ci >> du bilan : reste a debiter, reste a encaisser
  et solde prevu au dernier jour du mois.
- Montants affiches sur les graphiques du bilan.
- Tri des tableaux : cliquez sur le titre d'une colonne (dates, montants,
  libelles). Un second clic inverse l'ordre.
- Saisie des montants : la virgule et le point du pave numerique donnent
  le meme resultat (12,50 = 12.50).
- Notice complete integree (bouton << Notice >> du menu de gauche).
